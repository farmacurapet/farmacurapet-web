# DoaFarmaPet - Escopo Técnico

## 1. Módulos do Sistema
- Cadastro de Usuários (Integração ViaCEP, Login, Esqueci a Senha, Perfil)
- Farmácia Solidária (Cadastro de Doação -> Clique redireciona para o WhatsApp)
- Pets (Adoção de ONGs e Animais Perdidos/Achados)
- Utilidade Pública (Hospitais Recife/UFRPE com botões de Ligar e Mapas)
- Monetização (Espaços para Banners de Anúncios)

## 2. Tecnologias Recomendadas
- Frontend: Flutter ou React Native (Android/iOS)
- Backend/Banco de Dados: Firebase (Google) ou AWS Amplify (Amazon) - para login e armazenamento rápido de dados.
